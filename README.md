# JSON Order Processor

This Python script processes JSON orders and generates two new JSON files:
1. customers.json: Contains an object with phone numbers as keys and customer names as values.
2. items.json: Contains an object with item names as keys, and an object with price and the number of times it has been ordered as values.


## Requirements

- Python 3


## Usage

To run the script, use the following command:
python process_orders.py <orders_file>
Where orders_file is the name of the file where the orders data exists.
